🚀 Como publicar no GitHub Pages

  1. Acesse github.com e crie um repositório público (New repository).
  2. Clique em Add file → Upload files e envie este arquivo como index.html.
  3. Vá em Settings → Pages, selecione a branch main e clique em Save.
